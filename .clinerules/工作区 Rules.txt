# [Workspace Environment & Engineering Constraints]
# At the start of every session, read and strictly adhere to SEMANTIC_CLOSURE.md.

## 0. HIGHEST PRIORITY: STOP IMMEDIATELY UPON TASK COMPLETION
- **Strict Scoping**: Process ONLY requested tasks. Never autonomously alter configs, install packages, or create commits.
- **Halt Condition**: Cease tool calls immediately when user query is answered, changes are validated, or blockers occur.
- **Post-Tool Self-Check**: Ask "Is request satisfied?" after every tool call. If YES, stop immediately.

## 1. Tech Stack & Engineering Rules
- Framework: Astro SSR/Static. Adhere to standard lifecycle and routing conventions.
- Environment: VS Code + Cline. Prefer headless, scriptable tools over interactive commands.
- i18n & Structure: Single source of truth. Audit primary fallback config before editing. Preserve exact JSON/TS key hierarchies.
- SEO & Conversion: Ensure strict semantic SEO, GEO schema integrity, and inquiry conversion flow stability.

## 2. Undefined Slug Prevention (CRITICAL)
- NEVER use `|| undefined` in `getStaticPaths` params. Use `|| ''` instead.
- ALWAYS use full fallback chain for slug interpolation:
  `params: { slug: entry.slug || entry.id?.replace(/\.(json|md)$/, '') || '' }`
  `href={`/path/${e.slug || e.id?.replace('.json','') || ''}/`}`
- Run `node scripts/check-undefined-slugs.mjs` before creating/editing `[...slug].astro`.

## 3. Temp File Self-Cleanup
- Delete ALL temporary scripts/logs (`_*.mjs`, `temp*.*`, `out.txt`, `fix*.py`) created during the session.
- Run `git status --short` before concluding to ensure no untracked file remains.

## 4. Closed-Loop Engineering Principle
- Follow unified loop: Input → Compute → Store → Output → Improve → Re-input. Prefer idempotent scripts.

## 5. Model Protocol & Secrets
- Model: MiniMax-M3 via OpenAI-compatible endpoint (`https://api.minimaxi.com/v1`).
- Secret: Store API key ONLY in `.env.production` (`MINIMAX_API_KEY`). Never inline in tracked files.

## 6. Scope & Output Discipline
- Minimal action: Direct text answers for simple queries without tools.
- Length limit: Keep replies concise (<=15 lines). No unsolicited refactoring plans or fabricated progress history.
