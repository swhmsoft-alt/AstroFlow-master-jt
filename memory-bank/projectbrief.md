# Project Brief: AstroFlow (BOZE CNC Ti)

## Core Mission
A high-performance, multi-language (12 locales) Astro v5 static site for **BOZE CNC Ti** — a precision titanium CNC machining manufacturer. The site serves as a global engineering & lead-generation hub, targeting aerospace, medical, energy, and industrial equipment buyers.

## Key Requirements
1. **Global B2B Lead Generation** — RFQ forms, engineering tools, technical content to convert visitors
2. **Multi-language SEO** — 12 languages with hreflang, localized URLs, i18n content collections
3. **Semantic SEO Excellence** — JSON-LD structured data, OG/Twitter meta, breadcrumb, canonical URLs
4. **Knowledge Graph** — Equipment, materials, capabilities, industries, standards as interconnected content
5. **Zero-JS by default** — Islands architecture with minimal client JS

## Technology
- **Framework:** Astro v5 (static output)
- **UI:** Tailwind CSS v4, custom theme system
- **Interactive:** React 19 (only CADUpload component)
- **Animation:** motion library (vendor-bundled)
- **Icons:** lucide-react (vendor-bundled)
- **Deployment:** Static FTP upload to cnc.bozemetal.com
