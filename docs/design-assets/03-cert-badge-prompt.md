## Alternative: Manual Creation

Since these are simple text pills, they can be created directly in any image editor:

1. Create pill shape (rounded rect, radius=14px)
2. Fill: `#1E293B`, Stroke: `#3B82F6` 1px
3. Text: "AS9100D" / "ISO 13485", Inter Bold 11px, `#F8FAFC`
4. Export as transparent PNG
